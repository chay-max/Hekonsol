## Hekonsol

## What is Hekonsol?
it is a AI driven console tools that will help Developers to read and understand error messages more easily and quicker. 

## Problem Statement
Many developers struggle with understanding error messages, so what will they do? many of them will changing windows and search for the error messages that leads to wasting time and productivity. 

## How Hekonsol solves this problem?
First, Hekonsol will read the error message and understand it. Then it will provide the developer with a solution to fix the error message right into their console using an easy humanized language. This will save time and increase productivity for developers.

## Benefits of using Hekonsol
  # First, it will save time for developers by providing solutions directly in the console.
  # Second, it will save tokens especially for vibecoders because they will not need to ask to their agentic ai to solve it that will increase the tokens consumption.
  # Lastly, it will help new developers to learn and knowing the type of error.

## Planned usages
  > hekonsol run -- python report.py
